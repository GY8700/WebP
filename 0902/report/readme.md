1. 웹(Web)과 인터넷(Internet)의 개념 및 차이

인터넷은 여러 컴퓨터가 서로 연결되어 정보를 주고받을 수 있도록 만들어진 네트워크라고 할 수 있다. 1969년 미국 국방성의 ARPA에서 시작되었으며, 컴퓨터마다 IP 주소를 이용해 서로 통신한다.
반면 웹(World Wide Web)은 인터넷을 이용하는 여러 서비스 중 하나이다. 웹 서버에 저장되어 있는 정보를 웹 브라우저를 통해 확인하고 이용하는 방식이다.
쉽게 생각하면 인터넷이 정보를 전달하기 위한 전체적인 도로라면, 웹은 그 도로를 이용해서 정보를 주고받는 하나의 서비스라고 볼 수 있다.


2. 웹 서버와 웹 클라이언트의 구조 및 동작 원리

웹 클라이언트는 사용자가 직접 사용하는 부분으로, 대표적으로 웹 브라우저가 있다. 사용자가 웹 페이지를 요청하면 브라우저가 웹 서버에 필요한 자료를 요청하고, 서버에서 받은 결과를 화면에 보여준다.
웹 서버는 웹 사이트를 운영하는 컴퓨터와 관련 소프트웨어를 의미한다. 웹 문서뿐만 아니라 이미지나 동영상 등의 여러 자료를 저장하고 있으며, 클라이언트의 요청이 들어오면 필요한 자료를 전달한다. 대표적인 웹 서버로는 Apache, NGINX, IIS 등이 있다.
웹 페이지의 주소인 URL은 여러 부분으로 이루어져 있다. 
예를 들어 http://www.oracle.com:80/technetwork/java/index.html과 같은 주소에는 통신에 사용할 프로토콜, 서버 주소, 포트 번호, 경로, 파일 이름 등의 정보가 포함되어 있다.
웹 브라우저와 서버는 HTTP를 이용해 통신한다. 기본적으로 브라우저가 서버에 요청을 보내고 서버가 필요한 문서를 전송하면 연결을 종료하는 방식으로 동작한다. 이러한 방식을 통해 많은 사용자가 동시에 웹 서비스를 이용할 수 있다.


3. 웹 문서와 기존 전자 문서의 차이

워드나 한글 파일과 같은 일반적인 전자 문서는 하나의 파일 안에 글이나 이미지 등의 내용이 포함되어 있고, 보통 작성자가 정해 놓은 순서에 따라 문서를 읽게 된다.
웹 문서는 HTML을 이용해 작성하며 여러 페이지가 각각 파일로 나누어져 있다. 또한 이미지나 동영상 같은 자료가 별도의 파일로 존재하고 HTML 문서에서 연결해서 사용하는 경우가 많다.
가장 큰 차이점 중 하나는 하이퍼링크라고 생각한다. 웹에서는 링크를 클릭하면 다른 페이지로 바로 이동할 수 있기 때문에 사용자가 원하는 순서대로 정보를 찾아볼 수 있다. 따라서 일반적인 전자 문서보다 자유롭게 내용을 탐색할 수 있다는 특징이 있다.


4. 웹 페이지를 구성하는 3가지 요소

웹 페이지는 크게 HTML, CSS, JavaScript 세 가지 요소를 이용하여 구성한다.

HTML(HyperText Markup Language) - 웹 페이지의 기본적인 구조와 내용

CSS(Cascading Style Sheets) - 웹 페이지의 모양

JavaScript - 웹 페이지의 동적 변경 및 응용 프로그램 작성


5. 웹 브라우저의 역사와 HTML5가 등장한 이유

최초의 웹 브라우저는 1990년 팀 버너스리가 개발한 WorldWideWeb이다. 이후 Mosaic, Netscape, Internet Explorer 등의 브라우저가 등장했고, 현재는 Chrome, Safari, Microsoft Edge 등 다양한 브라우저가 사용되고 있다.
HTML5가 등장하게 된 이유에는 여러 가지가 있다.

첫 번째는 Active-X나 Flash와 같은 비표준 기술의 사용으로 인해 브라우저마다 호환되지 않는 문제가 발생했기 때문이다.
두 번째는 스마트폰과 태블릿 같은 모바일 기기가 많이 사용되면서 기존 PC 중심의 웹 환경만으로는 다양한 기기를 지원하기 어려워졌기 때문이다.

이러한 문제를 해결하고 특정 운영체제나 기기에 크게 의존하지 않는 웹 환경을 만들기 위해 HTML5와 같은 새로운 웹 표준이 필요하게 되었다.
